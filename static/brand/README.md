# Identidade Cloud Canvas

Marca original em SVG: uma nuvem com componentes conectados representa a criação manual de arquiteturas. O lettering tem traços arredondados, pequenas variações de altura e um sublinhado leve em Canvas.

- `cloud-canvas-logo.svg`: versão horizontal para fundo claro, em grafite e verde.
- `cloud-canvas-logo-dark.svg`: mesma geometria para fundo escuro, com letras claras e verde suave.
- `cloud-canvas-icon.svg`: símbolo sobre papel claro, reproduzido em `../favicon.svg`.

Todos os desenhos e letras são caminhos vetoriais próprios, sem fontes, filtros ou imagens externas. Preserve a geometria comum das versões, o contraste e a legibilidade no cabeçalho de 216 px e 155 px. A logo horizontal usa `viewBox="0 0 440 96"`; o símbolo, `0 0 104 96`.

O GIF de demonstração no README principal mostra uma versão anterior da marca.
